# Arte Madera - E-commerce
## Descripción
"Arte Madera" es un sitio web de e-commerce desarrollado con React y Vite, enfocado en la venta de productos de madera. La aplicación incluye un carrito de compras interactivo, con notificaciones y alertas personalizadas para mejorar la experiencia del usuario.
Utiliza Bootstrap para una barra de navegación responsiva.

## Características
*Catálogo de productos*: Explora una variedad de productos de madera disponibles para la compra.

*Carrito de compras*: Añade, elimina y actualiza la cantidad de productos en tu carrito.

*Notificaciones*: Implementación de Toastify para mostrar notificaciones de acciones como agregar productos al carrito.

*Alertas personalizadas*: Uso de SweetAlert para confirmar acciones importantes como la eliminación de productos del carrito.

*Diseño responsivo*: La interfaz está optimizada para dispositivos móviles y de escritorio.

## Tecnologías Utilizadas
*React*: Biblioteca de JavaScript para construir interfaces de usuario.

*Vite*: Herramienta de construcción rápida y ligera.

*Bootstrap*: Para una barra de navegación responsiva y estilizada.

*Toastify*: Para notificaciones de acciones del usuario.

*SweetAlert*: Para alertas y confirmaciones personalizadas.

*CSS/SCSS*: Estilos personalizados para un diseño atractivo y coherente.

*LocalStorage*: Persistencia del estado del carrito de compras entre sesiones.

## Funcionalidades
*Explorar Productos*: Navega por el catálogo de productos disponibles.

*Agregar al Carrito*: Añade productos al carrito con un solo clic.

*Modificar Carrito*: Cambia la cantidad de productos o elimínalos directamente desde el carrito.

*Finalizar Compra*: Procede al checkout cuando estés listo para realizar tu compra.
